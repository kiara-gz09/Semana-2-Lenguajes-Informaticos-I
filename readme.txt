## Guia de ejercicios semana 2

Ejercicio 1 — Verdadero o falso
Indicá si cada afirmación es verdadera (V) o falsa (F). Si es falsa, reescribí la afirmación
correctamente.

F 1. El DOCTYPE debe ir dentro del elemento <head>.
V 2. El atributo lang en <html lang="es"> le indica al navegador en qué idioma está
escrito el contenido.
F 3. El elemento <title> define el título que aparece dentro de la página visible al usuario.
F 4. Un documento HTML puede tener más de un elemento <body>.
V 5. La etiqueta <meta charset="UTF-8"> es necesaria para que el navegador muestre
correctamente tildes y la letra ñ.
F 6. El elemento <head> puede contener texto visible para el usuario.
V 7. <link rel="stylesheet" href="estilos.css"> se usa para vincular una hoja de estilos CSS
externa.
F 8. El elemento <script> solo puede ir al final del <body>, nunca en el <head>.
